Tone lab

Describe a sound when you need a new one.

Tone lab uses Claude and real device profiles to suggest settings from plain language, then lets you audition them on your rig. Auditioning only changes the live sound. It never saves over a preset.

{ How it works }

Three steps to Sunday.

  1. 01

    Catalog

    Add the presets you already use on each pedal. Do it once; add more whenever you save something new.

  2. 02

    Build

    Make a setlist. For each song, name the sections and pick which preset each pedal plays. Set the BPM.

  3. 03

    Send

    Review exactly what will change on the controller, switch by switch, then write. Every write is read back and checked.

{ Safety first }

Never overwrites what you made by hand.

Midiator only writes to a controller preset that's empty or still exactly what Midiator put there last time. Anything you edited yourself is marked and left alone. Nothing gets saved to your pedals, ever.

{ Questions }

Good to know.

Does Midiator change the presets saved on my pedals?

No. It only recalls presets and makes live edits you can hear. It never sends a save command to a pedal. The only thing it writes is your Morningstar controller's presets, and only the ones it made itself or empty ones.

Do I need to use the AI?

No. The main workflow, Setlists, Songs and My presets, is exact MIDI math with no AI involved. Tone lab is an optional extra for when you want help finding a new sound, and it needs your own Anthropic API key.

What do I need to get started?

A Mac, a Morningstar controller connected over USB, and your pedals connected to it by MIDI. Turn on MIDI Thru in the controller's settings so Midiator can reach your pedals.

Can I reuse the same banks every week?

Yes, that's the point. Midiator remembers what it wrote, so next week's setlist can reuse those banks. It updates what changed, clears switches the new song doesn't use, and leaves your own presets alone.

macOS comes first. Windows is on the list.
